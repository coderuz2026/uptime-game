# Публикация АПТАЙМ в Google Play: что делать по шагам

## Что уже готово (в этом репозитории)
- `uptime.aab` — файл для загрузки в Play. Лежит в последнем релизе: https://github.com/coderuz2026/uptime-game/releases/latest
- Пакет: `uz.uptimestudio.uptime`, целевая версия Android 16 (API 36) — этого требует Google Play.
- Политика конфиденциальности: https://coderuz2026.github.io/uptime-game/privacy.html
- Картинки в папке `store/`: `icon-512.png`, `feature-graphic.png` (1024×500), `screenshot-1…6.png` (1080×1920).
- Тексты страницы: `store/listing.md`.

## Что делаешь ты
1. Заведи отдельную почту для игры и впиши её в `web/privacy.html` (два места: «Связь» и «Contact»).
2. Зарегистрируй аккаунт разработчика: https://play.google.com/console/signup — 25 $ один раз, нужна банковская карта и подтверждение личности документом.
3. Добавь новый ключ подписи в GitHub: Settings → Secrets and variables → Actions → New repository secret. Два секрета: `KS_B64` и `KS_PASS` (значения в файле, который прислал Claude). После этого старый ключ из `android/keystore/` можно удалить.
4. В Play Console: «Создать приложение» → название «АПТАЙМ», язык русский, тип «Игра», бесплатно.
5. Заполни разделы (ответы ниже), загрузи картинки и тексты.
6. Тестирование → Закрытое тестирование → создай выпуск, загрузи `uptime.aab`, добавь почты 12 тестеров.
7. Через 14 дней подай заявку на доступ к рабочей версии.

## Ответы для анкет Play Console
**Доступ к приложению:** все функции доступны без ограничений (вход не нужен).
**Реклама:** нет. (Когда подключим настоящую рекламу — поменять на «да».)
**Возрастной рейтинг (анкета IARC):** категория «Игра». Насилие — нет. Секс — нет. Нецензурная лексика — нет. Наркотики, алкоголь, табак — нет. Азартные игры — нет. Общение между игроками — нет. Передача местоположения — нет. Покупки — нет.
**Целевая аудитория:** 13 лет и старше. Приложение не ориентировано на детей.
**Безопасность данных:** приложение не собирает и не передаёт данные пользователей. Шифрование при передаче — да (HTTPS). Удаление данных — не применимо, данные хранятся только на устройстве.
**Государственное приложение / новости / здоровье / финансы:** нет.
**Категория:** Игры → Приключения (или Симуляторы). Теги: сюжетная, детектив, симулятор.
**Контактные данные:** новая почта игры; сайт — https://coderuz2026.github.io/uptime-game/

## Важные правила
- Новый личный аккаунт обязан провести закрытый тест: минимум 12 тестеров, которые подключены 14 дней подряд. Набери 15–20 человек с запасом: если кто-то выйдет и станет меньше 12, срок может начаться заново.
- Тестеры должны установить игру из Google Play по ссылке теста, а не файлом APK.
- Версия из Google Play и версия с GitHub подписаны по-разному. На одном телефоне сначала удали одну, потом ставь другую.
- В версии для Play отключено предложение «скачать новый APK»: приложение там обновляет только сам магазин. Обновления игры (эпизоды, исправления) по-прежнему приходят сами при запуске.
- Каждая новая загрузка в Play требует номер версии больше прежнего: увеличь число в `android/version.txt`.
